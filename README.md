One funny line from a hopeless tech support agent to a desperate customer, for the make.fun competition [Have You Tried Turning It Off?](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b).

## The entry

```
I'm sorry your laptop's Wi-Fi is playing hide-and-seek; let's give it a gentle pep talk and see if it remembers how to connect.
```

## Run

```
python3 main.py
```

This writes the line above to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, or `/output` by default).
